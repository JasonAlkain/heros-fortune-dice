Privacy & saved data

What this application stores, what GitHub handles, and how to manage your saved data.

Updated November 15, 2026

01 / IN YOUR BROWSER

What the roller saves

The current application stores its saved data in your browser’s local storage. You do not need an account to use the roller.

Data stored by the application
DataPurposeHow to remove it
Action setupsRemember names, dice counts, die types, modifiers, and modes as you edit.Remove individual rows in the action tray, or clear browser site data.
Recent roll historyRemember up to 30 totals, kept die values, action labels, luck levels, modes, and times.Use Clear history on the roller, or clear browser site data.
Theme preferenceRemember a light or dark choice.Change it with the theme button, or clear browser site data to return to following the device setting.

Full candidate-die details remain only in the current page session. The current luck selection and target number reset on a fresh page load.

02 / APPLICATION BEHAVIOR

What the application sends

The current roller has no application server, AI-service connection, analytics scripts, advertising scripts, or embedded third-party media. Its application code does not upload your action setups, rolls, or theme preference.

Loading the site still requests its HTML, JavaScript, and stylesheets from GitHub Pages. This is different from saying that visiting the website creates no network traffic or hosting logs.

03 / HOSTING

GitHub handles website delivery

GitHub Pages hosts this site. GitHub’s documentation states that it logs and stores visitors’ IP addresses for security purposes, whether or not they are signed in to GitHub.

See GitHub Pages data collection and the GitHub General Privacy Statement for GitHub’s own handling of data. The roller’s maintainer does not control GitHub’s hosting-log retention.

04 / YOUR CONTROLS

Clearing and keeping your data

Clear history removes the application’s saved roll history while leaving your action setups and theme preference in place. It does not clear the latest result still displayed in each row; reloading resets those displays.

To remove all saved roller data from this browser, use your browser’s site-data controls for jasonalkain.github.io. Clearing data at that host can also affect other project sites you use under the same host.

Saved data does not sync between browsers or devices and does not move from the older ChatGPT-hosted address. There is currently no export/import or backup feature. Clearing site data, private-browsing behavior, or browser storage limits can cause saved data to be lost.

If local storage is blocked or unavailable, your theme, actions, or history may not persist after leaving the page.

05 / FEEDBACK & QUESTIONS

Information you choose to share

Source, issue reports, and comments in the GitHub repository are public. Opening a GitHub link takes you to GitHub, where its own privacy practices apply. Submitting an issue or comment shares the information you include with GitHub and readers of that public repository.

Do not include passwords, personal contact information, or private campaign details in a report. For questions about the application’s data handling, open an issue using only information you are comfortable publishing.

This page describes the current implementation. It will need updating if accounts, analytics, cloud storage, or other integrations are added.
